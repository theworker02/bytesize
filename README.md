![version 1.00](https://img.shields.io/badge/version-1.00-C9A227?labelColor=0B1F33)
![npm 1.0.0](https://img.shields.io/badge/npm-1.0.0-0B1F33)

Parse sizes like 1.5KiB and 2MB into bytes, and format integer bytes as IEC units.

## Install

```bash
git clone https://github.com/theworker02/bytesize.git
cd bytesize
npm install -g .
```

Package version: **1.00** (`1.0.0`).

## Usage

```bash
bytesize 1.5KiB
bytesize 1536
```
