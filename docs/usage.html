bytesize

Every flag, subcommand, and exit code. Same examples as the README.

Synopsis

bytesize [options] <size-or-bytes>
Tip: bytesize --help prints this text in the terminal. bytesize --version prints 1.0.0.

Flags and arguments

Flag / argumentMeaning
-h, --helpPrint detailed usage and exit 0.
-v, --versionPrint 1.0.0 and exit 0.
<digits>Integer bytes → IEC string (KiB, MiB, ...).
<n><unit>Parse to integer bytes. IEC units end in iB. SI units are KB/MB/GB (base 1000).

Exit codes

CodeMeaning
0Parsed or formatted.
1Missing argument or invalid size string.

Configuration

No configuration. Parse units: B, KB/MB/GB/TB/PB (SI), KiB/MiB/GiB/TiB/PiB (IEC). Format always uses IEC.

Worked examples

Success path

bytesize 2MB
bytesize 1048576
2000000
1MiB

Failure path

bytesize potato
invalid size: potato

Exit code is 1.
